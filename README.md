# Percolia.com

Site vitrine statique pour Percolia.

## Structure

- `index.html` — page principale
- `contact.html` — page de contact
- `css/style.css` — feuille de style partagée

## Développement local

Aucun outil de build requis. Ouvrez `index.html` dans un navigateur, ou servez le
dossier avec un serveur statique, par exemple :

```bash
python3 -m http.server
```

## Déploiement

Site statique — déployable tel quel sur GitHub Pages, Netlify, Vercel, etc.
